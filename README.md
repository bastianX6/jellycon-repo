# JellyCon Kodi Repository

This is the official Kodi addon repository for JellyCon (plugin.video.jellycon).

## Installation

### Install from Repository (Recommended)
1. In Kodi, go to **Settings** -> **File manager**
2. Add source: `https://bastianx6.github.io/jellycon-repo/` (name it "JellyCon Repo")
3. Go to **Add-ons** -> **Install from zip file**
4. Select the "JellyCon Repo" source
5. Install `repository.jellycon-1.0.0.zip`
6. Go to **Add-ons** -> **Install from repository** -> **JellyCon Repository**
7. Select **JellyCon** to install

### Direct Zip Installation
Alternatively, download and install the addon zip directly:
`https://bastianx6.github.io/jellycon-repo/zips/plugin.video.jellycon/plugin.video.jellycon-1.0.3-beta+py3.zip`
