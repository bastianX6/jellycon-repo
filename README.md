# JellyCon Kodi Repository

This is the official Kodi addon repository for JellyCon (plugin.video.jellycon).

## Installation

### Install from Zip
1. Download the zip from: `https://bastianX6.github.io/jellycon-repo/zips/plugin.video.jellycon/plugin.video.jellycon-1.0.3-beta+py3.zip`
2. In Kodi, go to **Settings** -> **Add-ons** -> **Install from zip file**
3. Navigate to the downloaded zip and install

### Add as Network Location
1. In Kodi, go to **Settings** -> **Add-ons** -> **Install from repository** -> **Add-on repository**
2. Add the network location: `https://bastianX6.github.io/jellycon-repo/`
3. Navigate to `zips/plugin.video.jellycon/` and install the addon
